# LoLoTube لولوتيوب

يوتيوب مفلتر للأطفال: يعرض مقاطع القنوات الهادفة فقط.

**الرابط:** https://alialsaffarmosuluniversity.github.io/KidsTube/

- مصمم للهاتف أولاً، وفيه زر للتحويل إلى عرض الحاسوب.
- 87 قناة هادفة في عشرة أنواع: الدينية، الأخلاقية، الفكرية، التعليمية، الترفيهية، الرياضية، الإنجليزية، لغات أخرى، النطق العربي، النطق الإنجليزي.
- واجهة بأسلوب يوتيوب: أنواع، رف قنوات، شبكة مقاطع، صفحة قناة، صفحة مشاهدة مع «التالي».
- المشغّل لا يقترح إلا من القناة نفسها، والتشغيل يكمل بمقاطع القناة المختارة.
- مفضلة وسجل مشاهدة على الجهاز، ويُثبَّت على الهاتف كتطبيق.

قائمة القنوات ومقاطعها في `data.json`.

تصميم: لوجيكال كود | Logical Code


## واجهتان
- 👦 أولاد: واجهة زرقاء ومقاطع مناسبة للأولاد.
- 👧 بنات: واجهة وردية ومقاطع مناسبة للبنات.
- زر ⏭️ تخطي فوق المشغّل للانتقال للمقطع التالي.
- استُبعدت القنوات الهندية والوثنية والمشبوهة.
